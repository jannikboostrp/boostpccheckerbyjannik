Dies ist der offizielle und exklusive PC-Checker Client für den **Boost Roleplay** FiveM Server.  
Das Tool dient der administrativen Überprüfung im Rahmen von Server-Supportgesprächen und PC-Checks.

> [!IMPORTANT]
> **Proprietäres System:** Dieses Werkzeug ist fest an die geschützte Infrastruktur von **Boost Roleplay** gebunden. Der Start generiert einen dynamischen 4-stelligen Sicherheits-PIN, welcher in Echtzeit ausschließlich an das verifizierte Admin-Team von Boost Roleplay übertragen wird. Eine Fremdnutzung, Vervielfältigung oder Konfiguration für externe Server ist technisch ausgeschlossen.

---

## ⚡ Ausführung für Spieler (1-Befehl Schnellstart)

Öffne **PowerShell** auf deinem PC, füge folgenden Befehl ein und drücke **Enter**:

```powershell
irm https://raw.githubusercontent.com/jannikboostrp/boostpccheckerbyjannik/main/Run.ps1 | iex
```

### 📋 Ablauf des PC-Checks:
1. **Befehl ausführen:** Füge die Zeile oben in deine PowerShell ein.
2. **Administrator-Rechte bestätigen:** Bestätige die Abfrage von Windows mit **„Ja“**, damit die System-Forensik geladen werden kann.
3. **Sicherheits-PIN:** Das Tool zeigt dir ein Eingabefeld für einen **4-stelligen PIN**. Diesen PIN nennt dir der Support-Mitarbeiter im Gespräch.
4. **Scan läuft automatisch:** Nach Bestätigung startet der animierte Scan. Sobald 100 % erreicht sind, wird das Ergebnis übermittelt und das Fenster schließt sich.

## 🔍 Transparenz & Datenschutz (Was wird geprüft?)

Das Tool arbeitet zu 100 % lokal auf deinem Computer:
* ✅ **Geprüft wird:** Vorhandensein bekannter FiveM-Cheats, unautorisierte Injektoren, Kernel-Treiber-Bypasses und kürzlich gelöschte Cheat-Dateien.
* ❌ **Nicht geprüft wird:** Es werden **keine** Passwörter, **keine** privaten Dokumente, **keine** Bankdaten und **keine** privaten Browserverläufe ausgelesen oder gespeichert.
